# contracts — 서로 주고받는 약속

**담당: 3명 공동.** 여기를 고치는 PR에는 전원이 리뷰어로 붙는다.

## 왜 이 폴더가 있나

셋이 각자 다른 언어로 짠다. 자바 클래스를 Go가 읽을 수 없고, Go 구조체를 파이썬이 읽을 수 없다.
그래서 **모두가 읽을 수 있는 형태**로 주고받을 모양을 적어 둔다.

이게 없으면 이런 일이 난다 — 한쪽은 `startAt`으로 보내고 다른 쪽은 `start_time`으로 읽으려다,
배포하고 나서야 전부 실패하는 것을 안다.

## 무엇을 담나

| 경로 | 내용 | 방향 |
|---|---|---|
| `db/` | 테이블 구조 설명서. 마이그레이션에서 자동 생성 | 3번 → 1·2번 |
| `sqs/` | 잡 메시지 스키마 (렌더·업로드·자막) | 3번 → 1·2번 |
| `api/openapi.yaml` | 공개 REST 명세 | 3번 → 2번 |
| `api/internal.yaml` | 서비스 간 내부 API | 3번 → 1·2번 |

## 무엇을 담지 않나

- 구현 코드 — 각 서비스 폴더에 둔다
- 설계 근거·대안 검토 — 그건 ADR이고, 정본은 `PokeClip-LLM-WIKI`에 있다

## 고칠 때 지킬 것

**필드 추가는 안전하고, 삭제·이름 변경은 위험하다.**
배포 순서에 따라 한쪽이 못 읽는 구간이 생긴다. 지우기 전에 반드시 상대와 배포 순서를 맞춘다.

## 상태

**아직 비어 있다.** 계약 초안이 이 저장소에서 가장 먼저 채워져야 할 것이다 —
세그먼트 이름 규칙이 정해지지 않으면 클립을 만들 수 없고, 잡 스키마가 없으면 워커를 짤 수 없다.
