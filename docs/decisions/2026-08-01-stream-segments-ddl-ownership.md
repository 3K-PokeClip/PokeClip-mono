# ADR-0001: stream_segments DDL 소유권을 1번으로 위임받고, 검증된 스키마를 정본으로 승격한다

날짜: 2026-08-01 / 상태: 확정 / 관련: POK-29, 구 POK-35, 계약-세그먼트인덱스 4절

## Context

`stream_segments`(세그먼트 인덱스 테이블)는 계약상 스키마 소유가 3번(데이터 계층)이었고, POK-29는 "3번의 정본 확정(구 POK-35) 전까지 임시 DDL로 개발"하는 전제였다. POK-29 구현이 끝난 시점에 3번이 "우리(1번)가 기록하는 테이블은 우리가 만들었으면 좋겠다"고 소유권 위임 의사를 밝혔다(kty·3번 대화, 2026-08-01). 이때 선택지는 둘: 지금까지 쓰던 스키마를 정본으로 승격하느냐, 새로 설계하느냐.

## Decision

1. **테이블 생성·DDL 소유 = 1번.** POK-29의 스키마(`media/internal/index/ddl.go`)를 그대로 **정본으로 승격**한다.
2. **컬럼 추가·변경·삭제 = 3번 승인 필수 유지.** 이 테이블을 3번(클립 서비스)이 읽으므로, 소비자 보호 절차는 소유권 위임과 무관하게 존속한다(kty 확정: "생성은 우리가, 변경은 승인 하에").
3. RDS(프로덕션) 적용 절차는 AWS 배포 시점에 별도 결정한다. 그 전까지 부팅 시 `ENSURE_SCHEMA` 게이트로 로컬 compose에서만 생성한다.

## Alternatives Considered

**A. 스키마 재설계 후 새로 생성**
- Pros: 백지에서 3번 관점 요구(파티셔닝, enum 전략 등)를 반영할 기회.
- Cons: 현행 스키마는 계약 문서의 초안을 그대로 구현한 것이고, 테스트 159건·실환경 실측 6회·재시작/PG 장애 관통 검증을 통과했다. 재설계는 이 검증을 전부 무효화하면서 얻는 것이 없다(YAGNI). 미결 항목(파티셔닝·enum)은 필요해질 때 "컬럼 변경 승인" 절차로 반영 가능.
- Why not: 비용만 있고 편익이 없음.

**B. 승격하되 컬럼 변경 승인권까지 1번으로**
- Pros: 변경 속도.
- Cons: 이 테이블의 소비자가 3번이다. 생산자가 소비자 동의 없이 스키마를 바꿀 수 있으면 읽는 쪽이 조용히 깨진다.
- Why not: 소비자 보호가 속도보다 우선. kty가 명시 기각.

## Consequences

- Positive: U12(정본에 UNIQUE 포함 여부) 종결 — 멱등 최후 방어선이 정본 사양이 됨. "임시→정본 교체" 마이그레이션 단계 자체가 소멸. 구 POK-35의 테이블 생성 스코프 제거(남는 스코프: 컬럼 정책·인덱스 전략 리뷰 — 3번 승인 절차로 흡수).
- Negative: 스키마 운영 책임(백업·마이그레이션 절차·RDS 권한 설계)이 1번으로 이동 — AWS 배포 전에 결정 필요. 계약 문서(위키) 4절 소유 표 갱신 필요.

## 추기 2026-10-19 — dev 는 시험을 위해 손으로 적용한다(POK-368)

- **무엇:** 정본 `schemaDDL`(고정 커밋 `ef5c23f1` 의 `media/internal/index/ddl.go`)을 dev 서버 상자의 공유 postgres(3번 서버 넷이 함께 쓰는 DB)에 1번이 한 번 손으로 적용했다. 이어서 조각 창고에 이미 있던 조각 22개(`streams/p79b-447fb75c/…`)를 가리키는 시험 줄 22개를 넣었다.
- **왜:** dev 에는 이 표를 만들고 채우는 인덱서가 없다. 그래서 3번이 dev 에서 렌더 · 썸네일을 시험할 수 없었다(POK-332).
- **결정 3 과의 관계:** 「로컬 compose 에서만 생성」 에 dev 예외 하나를 더한다. RDS(프로덕션) 적용 절차는 여전히 AWS 배포 시점에 정한다.
- **운영 규칙:** 결정 1 · 2 의 소유 · 승인 규칙은 그대로다. `ddl.go` 가 바뀌면 dev 재적용은 1번 몫이다. 3번은 이 표를 읽기만 한다. dev 에서는 인덱서가 없으므로 치우개(`BROADCAST_REAPER_ENABLED`)를 켜지 않는다. 지울 때는 시험 줄을 먼저 지우고, 치우개 · 썸네일 · 떼기 스위치가 꺼진 것을 확인한 뒤 표를 지운다.
- **나중에 정할 것:** dev 에 인덱서가 붙는 날 이 표를 이어 쓸지는 그때 정한다.
- **기록:** POK-368 코멘트 · 적용 블록과 결과는 1번 볼트 raw.
