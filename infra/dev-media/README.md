# 임시 데모 media 서버 — **만료일 2026-08-24** (그날까지 이 디렉토리를 통째로 삭제한다)

멘토 데모(2026-08-21) 한 번을 위해 띄우는 **일회용** 구성이다. 팀 공용 로컬 환경이 아니다.
같은 저장소의 `docker-compose.yml`·`infra/compose/`가 팀 공용이고, 이 디렉토리는 그것과 **수명이 다르다**.

- **무엇을 보여주나**: OBS가 SRT로 송출한 방송을 브라우저에서 재생하다가, 시크바를 20분 전으로 끌면
  그 시점 영상이 나오고 LIVE 버튼으로 현재로 돌아온다. 되감기 가능한 폭은 1시간이다.
- **왜 별도 서버인가**: 팀 상시 dev EC2를 건드리지 않기 위해서다. 이 구성은 신규 EC2 1대에만 올라가고,
  데모가 끝나면 인스턴스·보안그룹·DNS 레코드와 **이 디렉토리까지** 함께 사라진다.
- **왜 자체 재생 페이지인가**: MediaMTX 내장 플레이어는 일시정지 후 재생하면 라이브 위치로 강제 점프해서
  되감기 시연 자체가 성립하지 않는다(2026-08-18 조사).

> 이 구성이 어긴 팀 결정(퍼블릭 서브넷 직노출·시크릿 보관 위치·비특권 승계 수단)과 그 기한은
> [**ADR-040**](https://github.com/3K-PokeClip/PokeClip-LLM-WIKI/blob/main/adr/ADR-040_%EC%9E%84%EC%8B%9C%EB%8D%B0%EB%AA%A8-media%EC%84%9C%EB%B2%84-%EA%B8%B0%ED%95%9C%EB%B6%80%EC%98%88%EC%99%B8.md) 에 기록돼 있다.

## 구성도

```
 OBS (kty 노트북)
   │  SRT  udp/8890   streamid=publish:<DEMO_PATH>, passphrase
   ▼
┌─ EC2 (t3.small, 퍼블릭 서브넷) ───────────────────────────────┐
│                                                              │
│  mediamtx 컨테이너 ── LL-HLS 먹싱 ── /dvr (세그먼트 900개=1h) │
│    ▲ 8888(내부 전용, 외부 미공개)                             │
│    │ proxy_pass                                              │
│  edge 컨테이너 (nginx) ── /player.html 정적 서빙              │
│    ▲ tcp/8888  ← 외부에 열리는 유일한 TCP 포트                │
└────┼─────────────────────────────────────────────────────────┘
     │  보안그룹: udp/8890 · tcp/8888 을 팀 공인 IP/32 에서만 허용
   브라우저 http://media-dev.pokeclip.com:8888/player.html?p=<DEMO_PATH>
```

접근 통제는 3층이다 — **보안그룹(IP/32)** + **랜덤 경로**(24자 hex) + **SRT publish passphrase**(32자, 송출 전용 — 재생용 `srtReadPassphrase`는 두지 않는다).
읽기용 Basic 인증층은 넣지 않았다(시연 중 인증 팝업이 뜨고, IP 제어 지점이 둘로 갈라져 당일 갱신을 한쪽만 하기 쉽다).
실질 방어는 보안그룹이며, 랜덤 경로는 은닉일 뿐 인증이 아니다.

## 파일

| 파일 | 무엇 |
|---|---|
| `RUNBOOK.md` | AWS 생성 → 배포 → 실측 검증 → 데모 당일 → 철거. **명령은 전부 여기에만 있다** |
| `compose.yml` | mediamtx + edge(nginx) 2서비스 |
| `mediamtx.demo.yml.tmpl` | MediaMTX 설정 템플릿(플레이스홀더 2개) |
| `render.sh` | 템플릿 + `.env` → `$DEMO_HOME/mediamtx.demo.yml` (가드 6종, 이 구성의 유일한 자동 검사) |
| `nginx.conf` | 8888 단일 오리진 — 정적 페이지 + MediaMTX 프록시 |
| `player.html` | hls.js 재생 페이지(되감기 시크바·LIVE 버튼) |
| `.env.example` | 값은 빈칸 + 생성 명령만. **실값은 여기 적지 않는다** |

설정값(세그먼트 길이·DVR 개수·포트)은 위 파일들에만 적는다. 문서에 같은 값을 두 번 적지 않는다 — 한쪽만 고쳐지기 때문이다.
