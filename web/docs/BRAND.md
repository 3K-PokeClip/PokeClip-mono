# PokeClip 브랜드 가이드

> **한 줄 소개:** PokeClip — 라이브의 순간을 발견해, 주머니에 담다.
> 기능 중심 표현: *실시간 라이브에서 하이라이트를 발견하고 바로 클립으로.*

이 문서는 POK-95에서 확정한 브랜드 자산(로고·파비콘·컬러 팔레트·타이포 스케일)의 정본이다.
컬러·타이포의 상세 토큰 체계는 [COLOR_SYSTEM.md](./COLOR_SYSTEM.md)와 `src/styles/primitives/`를 따른다.
디자인 원본(시안·사용 예시·내보내기 프레임)은 Figma **PokeClip Brand** 파일에 있다.

---

## 1. 브랜드 스토리

라이브의 모든 순간을 계속 지켜볼 수는 없다. 하지만 재미있는 장면은 언제든 갑자기 찾아온다.
PokeClip은 흘러가 버릴 그 순간을 발견하고, 바로 꺼내볼 수 있는 클립으로 주머니에 담아준다.

**로고 콘셉트: "라이브의 순간을 주머니에 담다"**

| 요소 | 의미 |
|---|---|
| 주머니 형태 | 'Poke'에서 연상되는 포켓. 라이브의 재미있는 순간을 나만의 주머니에 간직한다 |
| 재생 아이콘 | 실시간 라이브와 영상 콘텐츠의 상징. 로고만 봐도 영상 서비스임을 직관적으로 인지 |
| 마젠타 포인트 | 라이브 속에서 발견된 결정적 순간(하이라이트). 동시에 영상을 선택·잘라내는 클립 액션 |
| 부드럽고 둥근 형태 | 자동화 기술 기반이지만 차갑지 않게 — 크리에이터와 시청자 모두 부담 없는 이미지 |

## 2. 로고 유형

원본 파일: `apps/web/public/brand/` (SVG, 워드마크는 아웃라인 처리 완료)

| 유형 | 파일 | 용도 |
|---|---|---|
| 심볼 | `pokeclip-symbol.svg` | 파비콘·앱 아이콘·좁은 공간. 다크 배경 전용(재생 마크 화이트) |
| 가로형 (다크 배경용) | `pokeclip-logo-horizontal.svg` | 전역 헤더·다크 UI. 워드마크 화이트 단색 |
| 가로형 (라이트 배경용) | `pokeclip-logo-horizontal-light.svg` | 라이트 UI·문서. 워드마크 `#141517` 단색, 재생 마크 다크 |

- 워드마크 서체: **Pretendard SemiBold(600)** 아웃라인 — UI 서체와 동일 계열. 재생성: `node scripts/build-wordmark.mjs` (PretendardVariable.woff2에서 패스 생성, Figma 불필요)
- 워드마크는 **단색**만 사용한다 — 다크 배경 화이트 / 라이트 배경 `#141517`(gray-1000). 색은 심볼이 담당한다.

## 3. 컬러 규정

브랜드 컬러는 디자인 시스템 토큰(`--pc-*`)의 확정 선언이다. 임의 변경 금지.

| 역할 | 토큰 | HEX | 의미 |
|---|---|---|---|
| **브랜드 메인** | `--pc-primary-500` | `#586FC4` | 인디고 — 기술 신뢰·안정적 라이브 처리·스마트한 자동화 |
| **브랜드 포인트** | `--pc-point-500` | `#D63F9F` | 마젠타 — 재미·몰입·실시간으로 터지는 하이라이트 에너지 |
| 다크 캔버스 | `--pc-gray-1000` | `#141517` | 다크 퍼스트 기본 배경 |
| 라이트 캔버스 | `--pc-gray-50` | `#EEF0F3` | 라이트 테마 배경 |

두 색의 대비가 곧 브랜드 성격이다 — *차분한 기술(인디고) 위에서 특별한 순간(마젠타)이 발견된다.*

**상태색 (시맨틱, 다크 테마 기준):** success `#30AC04`(green-600) · warning `#FFD607`(yellow-500) · danger `#FF4D6A`(red-400) · info `#00DFFF`(cyan-500) — 전체 램프·라이트 테마 값은 [COLOR_SYSTEM.md](./COLOR_SYSTEM.md) 참조.

## 4. 여백과 최소 사이즈

- **클리어 스페이스:** 로고 사방에 심볼 높이의 **25%**(0.25H) 이상 여백을 확보한다. 이 영역에 다른 그래픽·텍스트를 두지 않는다.
- **최소 사이즈:** 심볼 **24px**, 가로형 로고 너비 **120px**. 이보다 작게 사용하지 않는다 (파비콘 16px는 전용 파일 `icon.svg`/`favicon.ico`만 허용).

## 5. 금지 사항

1. 형태·비율 변형 금지 (기울이기, 부분 확대, 좌우 반전 포함)
2. 지정 색상 외 임의 색 적용 금지 (단색 필요 시: 다크 배경 화이트 / 라이트 배경 gray-1000 단색만 허용)
3. 그림자·외곽선·그라데이션 등 효과 추가 금지
4. 배경 대비가 부족한 곳에 사용 금지 (다크 배경엔 다크용, 라이트 배경엔 라이트용 파일 사용)
5. 워드마크 서체 임의 교체·재조판 금지

## 6. 타이포그래피

UI 서체는 **Pretendard Variable** (self-host, `--pc-font-sans`), 기본 크기 **15px**. 로고 워드마크도 같은 Pretendard(SemiBold 600 아웃라인)를 사용해 브랜드와 UI의 톤을 통일한다.

| 토큰 | px | rem | 용도 |
|---|---|---|---|
| `4xl` | 48 | 3 | 히어로 타이틀 |
| `3xl` | 36 | 2.25 | 페이지 타이틀 |
| `2xl` | 28 | 1.75 | 섹션 타이틀 |
| `xl` | 22 | 1.375 | 카드 타이틀 |
| `lg` | 18 | 1.125 | 강조 본문 |
| `md` | 15 | 0.9375 | **기본 본문 (base)** |
| `sm` | 13 | 0.8125 | 보조 텍스트 |
| `xs` | 12 | 0.75 | 캡션 |
| `2xs` | 11 | 0.6875 | 라벨·뱃지 |

행간 `tight 1.2 / snug 1.35 / normal 1.5 / relaxed 1.7` (한글 본문은 1.5 미만 금지), 굵기 `400/500/600/700` — 정본: `src/styles/primitives/typography.css`.

## 7. 파비콘·앱 아이콘

| 파일 | 스펙 | 비고 |
|---|---|---|
| `apps/web/src/app/icon.svg` | SVG, 테마 대응 | `prefers-color-scheme`로 재생 마크 색 전환 |
| `apps/web/src/app/favicon.ico` | 16/32/48 멀티사이즈 | 레거시 폴백 (생성물) |
| `apps/web/src/app/apple-icon.png` | 180×180 불투명 | 다크 캔버스 위 심볼 (생성물) |

Next.js 16 파일 컨벤션으로 자동 `<link>` 생성 — `metadata.icons` 설정 불필요.
**재생성:** `pnpm --filter @pokeclip/web run build:brand` (원본 심볼 SVG 변경 시)

## 8. 모션 (스플래시)

심볼 리빌 애니메이션 원본: `apps/web/public/brand/motion/` (`logo_animated.svg`, `motion.css`)

- **1600ms** 단일 클록: 마젠타 점화(8–20%) → 인디고 리본 스윕(20–72%) → 재생 마크 팝(66–100%, 오버슈트 1.06)
- `prefers-reduced-motion`: 즉시 최종 프레임 표시
- 상세 스펙·QA 기록: 로고 모션 프로젝트의 `motion_spec.md` (pokeclip-v3-motion)
