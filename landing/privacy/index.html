1. 개인정보의 처리 목적

운영자는 다음 목적으로 개인정보를 처리하고, 목적이 바뀌면 미리 알립니다.

  • 회원 가입, 본인 식별, 로그인 유지
  • 서비스 제공: 방송 수신과 보관, 하이라이트 후보 표시, 클립 편집·렌더링, YouTube 업로드, 편집자 초대와 위임
  • 치지직·SOOP·YouTube 연동과 그 유지
  • 서비스 알림과 중요한 고지 발송(서비스 안 알림과 이메일): 작업 결과, 초대, 약관·처리방침 변경, 보안 관련 안내
  • 부정 이용 방지와 보안(스트림 키·페어링 남용 차단)
  • 문의와 권리 행사 요청에 대한 응대

광고성 정보는 보내지 않습니다. 앞으로 보내게 되면 이 방침을 바꾸고, 원하는 회원에게만 따로 동의를 받습니다.

2. 처리하는 개인정보 항목과 처리 근거

4. 개인정보의 파기 절차와 방법

  • 보유 기간이 지나거나 처리 목적을 이루면 5일 이내에 파기합니다.
  • 전자 파일은 복구할 수 없는 방법으로 삭제합니다.
  • 편집자 위임 이력처럼 지우면 다른 정보주체의 권리를 해치는 기록은 누구인지 알아볼 수 없게 바꿔(익명화) 남깁니다.
  • 이미 YouTube 등 연동 플랫폼에 게시된 영상은 운영자가 지울 수 없습니다. 회원이 그 플랫폼에서 직접 지워야 합니다.

5. 개인정보의 제3자 제공

운영자는 개인정보를 제3자에게 제공하지 않습니다. 다음은 회원의 지시에 따른 처리입니다.

  • 스트리머(또는 스트리머가 위임한 편집자)가 업로드를 요청하면 클립 영상과 제목·설명을 스트리머의 YouTube 채널로 보냅니다.
  • 스트리머가 위임한 편집자는 그 스트리머의 방송 데이터와 채팅 데이터를 볼 수 있습니다.

법령에 따라 수사기관 등이 정해진 절차로 요구하는 경우는 예외입니다.

8. 개인정보의 안전성 확보 조치

  • 개인정보에 접근할 수 있는 사람을 운영에 필요한 팀원으로 한정합니다.
  • 연동 토큰과 스트림 키 비밀값은 암호화(AES-256)해 보관합니다.
  • 로그인 유지 토큰, 스트림 키 식별값, 페어링 코드는 원문을 두지 않고 해시로만 보관합니다.
  • 권한이 없는 요청은 대상이 있는지조차 드러나지 않게 거절합니다.
  • 영상은 서명된 쿠키로 권한 있는 회원만 재생할 수 있습니다.
  • 전송 구간을 암호화(HTTPS)하고, 서버 관리용 접속 포트를 외부에 열지 않습니다.
  • 로그에 이메일, 채팅 내용, 토큰을 남기지 않습니다.
  • 서버와 데이터는 Amazon Web Services 데이터센터의 물리 보안 아래 둡니다.

9. 자동 수집 장치의 설치·운영과 거부

  • 쿠키: 대시보드(app.pokeclip.com)에서 영상 재생 권한을 확인하는 쿠키 한 종류만 씁니다(유효 1시간).
  • 브라우저 저장소: 대시보드는 로그인 유지 정보(최대 14일), 화면 테마, 처음 사용 안내 진행 상태, 편집기 패널 위치를 브라우저에 저장합니다.
  • 서비스 소개 페이지(pokeclip.com)는 쿠키와 브라우저 저장소를 쓰지 않습니다.
  • 방문 분석, 광고, 행태정보 수집을 위한 쿠키나 도구는 쓰지 않습니다.

브라우저 설정에서 쿠키와 사이트 데이터를 막을 수 있습니다. 막으면 로그인 유지와 영상 재생을 쓸 수 없습니다.

10. 정보주체의 권리와 행사 방법

  1. 정보주체는 언제든 자신의 개인정보 열람, 정정, 삭제, 처리 정지를 요구할 수 있습니다. 회원은 계정 설정에서 정보를 확인하고 탈퇴할 수 있고, 그 밖의 요구는 아래 개인정보 보호책임자에게 이메일로 할 수 있습니다.
  2. 회원이 아닌 시청자도 같은 권리를 행사할 수 있습니다. 치지직 채널 ID나 SOOP 아이디, 닉네임, 해당 방송을 알려 주시면 확인한 뒤 처리합니다.
  3. 요구를 받으면 10일 이내에 처리하고 결과를 알립니다.
  4. 법정대리인이나 위임받은 사람을 통해서도 요구할 수 있습니다. 이때는 위임장이 필요합니다.
  5. 법령이 정한 사유가 있으면 요구를 거절할 수 있고, 그때는 이유를 알립니다.

11. 자동화된 결정

서비스는 정보주체에게 법적 효력이나 중대한 영향을 주는 완전히 자동화된 결정을 하지 않습니다. 하이라이트 후보는 채팅량 통계로 표시하는 참고 정보이고, 사람에 대한 결정이 아닙니다.

12. 인공지능 관련 처리

현재 서비스에는 생성형 인공지능 기능이 없습니다. 회원 콘텐츠와 채팅 데이터를 인공지능 모델 학습에 쓰지 않습니다. 인공지능 기능을 도입하면 그 용도, 처리하는 정보, 학습 활용 여부를 이 방침에 추가하고 미리 알립니다.

13. YouTube API 서비스와 Google 사용자 데이터

  • 서비스는 YouTube API 서비스를 사용합니다.
  • 접근하는 정보: 연동을 확인하는 YouTube 채널 ID와 채널 이름, 동영상 업로드 권한(youtube.upload)과 채널 조회 권한(youtube.readonly).
  • 이용 방법: 스트리머가 서비스에서 클립을 확인하고 업로드를 요청하면, 그 클립과 제목·설명을 스트리머의 채널에 스트리머가 고른 공개 범위(공개·일부 공개·비공개)로 올립니다. 스트리머가 요청하지 않은 영상은 올리지 않으며, 올린 뒤의 공개 범위 변경과 삭제는 스트리머가 YouTube에서 할 수 있습니다.
  • 공유: 5절과 7절에 적은 경우 말고는 공유하지 않습니다.
  • 저장: 접근 토큰은 암호화해 두고 연동 해제나 탈퇴 때 바로 지웁니다. 채널 정보는 연동 해제나 탈퇴 때 지체 없이 지웁니다.
  • 권한 철회: Google 보안 설정 페이지에서 언제든 서비스의 접근 권한을 철회할 수 있습니다. 서비스 안에서 연동을 해제해도 Google 쪽 권한은 남을 수 있으니 이 페이지에서 함께 철회하세요.
  • Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.
  • PokeClip이 Google API로 받은 정보를 쓰고 다른 앱으로 보내는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. Google 사용자 데이터를 광고나 인공지능 모델 학습에 쓰지 않습니다.
